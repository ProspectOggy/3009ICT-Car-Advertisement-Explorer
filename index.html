About this project

This dashboard explores a cleaned dataset of 30,237 car advertisements covering 76 brands, manufactured between 1990 and 2023. Every chart and the listings table update instantly as you change the filters.

Data preparation

  • Kept the columns needed for analysis: model, brand, body type, condition, year, mileage, price, fuel, transmission, drive type and specifications.
  • Standardised drive type labels (FWD, RWD, AWD, 4WD) and replaced missing values marked with “-” by “unknown”.
  • Rounded prices to the nearest dollar and mileage to the nearest kilometre.

Notes

  • The dataset has no listing date, so price trends are shown by year of manufacture.
  • Medians are used instead of means because a small number of luxury vehicles (over $1M) heavily skew averages.
