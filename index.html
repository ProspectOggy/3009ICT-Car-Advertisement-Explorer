Interactive Visualisation 1

Mileage vs Price

This scatter plot shows the relationship between vehicle mileage and advertised price. Hover over individual listings for vehicle details, click New or Used in the legend to show or hide them, and use the filters to explore different sections of the dataset.

To keep the chart responsive, a random sample of up to 4,000 matching listings is plotted. The mileage axis stops at the 99th percentile so a few extreme odometer readings do not compress the rest of the data.

Methodology

This dashboard uses the cleaned dataset produced during Tasks 1 and 2 of the assignment. Invalid values and outliers were reviewed during data cleaning, missing numerical values were imputed using the median, and categorical missing values were treated using the mode where appropriate.

For the website, only the columns needed for the charts and table were kept, drive type labels were shortened (FWD, RWD, AWD, 4WD), and any remaining values recorded as “-” are shown as “unknown”. For dashboard display, prices were rounded to the nearest dollar and mileage to the nearest kilometre.

The dataset does not include the date each advertisement was listed, so price trends are shown by year of manufacture. Medians are used for the summary statistics because a small number of luxury vehicles priced above $1 million would heavily affect the averages.
